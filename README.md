# TileBasedDDG3

What went well?

Tried something new and it went well! I had never used grid canvases and it worked out. I found a youtube video on how to make the grids click and draggable and eveyrthing worked like a charm!

What didn’t go well?

First issue I ran into was changing the rotation of the player. It was only rotating in one direction and wouldn't let up. I later learned from you (the professor) about Euler angles. And after correcting my code fixed a lot

What challenges did you face? (Technical, creative, or production)

It was a lot of new learning and messing with render textures to get everything right. I wish I had more time to add better assets use volumes to achieve the texture I was going for. 
I also tried using grids for to impact the game space live and to properly match it set grid positions. So, figuring that out took a good bit.

What can you do differently next time?

Without extra time I feel like the outcome would be the same. Now that I know how a lot of the grid canvas stuff works, I feel like that process would go faster.
Though I do wish I planned out the UI on paper before starting so I didn't have to spend time trying to figure out what looks best multiple times.
